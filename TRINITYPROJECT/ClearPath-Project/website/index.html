About the model

Algorithm

Supervised learning: a Decision Tree Classifier in a scikit-learn pipeline (StandardScaler, then tree), trained in Google Colab and exported to model.js.

Measured results

Limits to keep in mind

  • The sample data looks simulated and is not real student data.
  • Patterns are associations, not causes.
  • Use it to start a conversation about support. Never to grade, rank or label a student.
