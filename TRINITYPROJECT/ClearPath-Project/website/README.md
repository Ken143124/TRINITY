# ClearPath Exam Check

CST 9/L Final Project, UM Tagum College.

ClearPath estimates a student's chance of scoring **70 or higher** on an exam from six study habits. It uses a decision tree trained on 10,000 student records and shows the questions the tree asked. Everything runs in the browser and nothing is sent anywhere.

## How to run

No install or build step is needed. Download the files and open `index.html` in any modern browser.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page layout |
| `styles.css` | Styling (plain CSS, light and dark mode) |
| `app.js` | Scales the inputs, walks the tree, and builds the advice shown on the page |
| `model.js` | Fitted StandardScaler and decision tree, generated by the notebook (do not edit by hand) |
| `ClearPath_Decision_Tree.ipynb` | Google Colab notebook that trains and evaluates the model and exports `model.js` |
| `notebook.csv` | Student dataset used for training and validation |

## Model

- **Type:** Supervised learning, `Pipeline(StandardScaler, DecisionTreeClassifier(max_depth=5, min_samples_leaf=50, random_state=42))`
- **Inputs:** study hours, attendance, sleep hours, internet use, assignments completed, previous score
- **Target:** On Track (70+) or Needs Support
- **Split:** 7,000 training rows and 3,000 validation rows

| Metric | Value |
|--------|-------|
| Training accuracy | 89.0% |
| Validation accuracy | 88.4% |
| Always-On-Track baseline | 84.4% |
| Needs Support caught (recall) | 55% |
| Needs Support correct (precision) | 65% |

## Limits

- The dataset looks simulated and is not real student data.
- The model finds associations, not causes.
- The exam score is not a model input because the dataset label is defined by it.
- Use it to start a conversation about support. Never use it to grade, rank or label a student.
